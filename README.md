# HR Analytics and Employee Attrition Dashboard

An interactive **HR Analytics dashboard built with Microsoft Power BI**
to explore employee data, understand workforce patterns, and analyze
employee attrition. The report is designed to help HR teams and
decision-makers identify trends and make more data-informed workforce
decisions.

## Project Overview

This project uses data visualization and HR metrics to present workforce
information in a clear, interactive report. Users can explore
employee-related patterns and compare results across available
categories and filters.

## Objectives

-   Analyze employee attrition and workforce trends.
-   Explore employee demographics and job-related information.
-   Present HR data through interactive Power BI visuals.
-   Make workforce patterns easier to understand for reporting and
    decision-making.

## Tools and Technologies

-   **Microsoft Power BI** --- dashboard development and interactive
    visualizations
-   **Power Query** --- data preparation and transformation
-   **SQL** --- querying and analyzing structured data
-   **Microsoft Excel** --- data inspection and supporting analysis

## Dashboard Highlights

## Project File

-   `HR Analysis.pbix` --- Power BI report file.

## How to Use

1.  Download or clone this repository.
2.  Install **Microsoft Power BI Desktop**.
3.  Open `HR Analysis.pbix` in Power BI Desktop.
4.  Use the report's visuals and available filters to explore the HR
    data.

> **Note:** If the report uses an external data source, configure the
> required connection and refresh the data in Power BI Desktop.
